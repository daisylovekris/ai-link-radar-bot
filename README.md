# TG Bot｜个人链接素材箱

## 一、项目目标

这是一个个人信息收集小助手。

我在 Telegram 里给机器人发送链接，机器人会自动识别、去重、识别平台，并保存成 Markdown 卡片到本地 `links.md`。

这个项目后续可以继续扩展为：

- 网页抓取入口
- AI 热点素材池
- Gemini 脱水器入口
- Obsidian / 本地知识库入库工具

---

## 二、当前已完成能力

### 1. 收集链接

机器人可以接收 Telegram 消息，并识别其中的链接。

支持链接类型：

```text
https://x.com/...
https://twitter.com/...
https://普通网页链接
```

保存流程：

```text
1. 先写入 Markdown 卡片，标题初始为“待抓取”。
2. 写入成功后，自动尝试抓取网页标题。
3. 标题抓取成功时，自动写回刚保存的卡片。
4. 标题抓取失败时，不影响卡片保存，标题保持“待抓取”，后续可用 /fetch_title 重试。
```

## 四、当前支持命令

### `/help`

查看机器人使用说明。

### `/health`

检查机器人是否在线。

回复示例：

```text
机器人在线，正在工作。
```

### `/stats`

查看当前 `links.md` 的链接统计，包括全部链接、待脱水数量、已处理数量和完成率。

回复示例：

```text
当前 links.md 统计：

- 全部链接：5 条
- 待脱水：5 条
- 已处理：0 条
- 完成率：0.0%
```

### `/recent`

查看最近保存的 3 条链接。也可以指定数量，例如：

```text
/recent 5
```

最多返回 10 条。

异常输入时，机器人会给出提示：

```text
/recent abc  → 数量无效，已按默认 3 条显示。
/recent 0    → 数量不能小于 1，已按默认 3 条显示。
/recent 999  → 最多只能显示 10 条，已按 10 条显示。
```

### `/todo`

查看待脱水链接。默认显示第 1 页，每页最多 5 条。

也可以指定页码，例如：

```text
/todo 2
```

异常页码时，机器人会给出提示：

```text
/todo abc  → 页码无效，已显示第 1 页。
/todo 0    → 页码不能小于 1，已显示第 1 页。
/todo 999  → 如果页码超出范围，机器人会提示当前可用页码。
```

### `/todo_links`

查看待脱水链接的简洁列表，只显示链接，不显示完整 Markdown 卡片。

默认显示第 1 页，每页最多 10 条。

也可以指定页码，例如：

```text
/todo_links 2
```

适合快速扫一眼、复制链接、检查积压。

异常页码时，机器人会给出提示：

```text
/todo_links abc  → 页码无效，已显示第 1 页。
/todo_links 0    → 页码不能小于 1，已显示第 1 页。
/todo_links 999  → 如果页码超出范围，机器人会提示当前可用页码。
```

### `/done`

把指定待脱水链接标记为已脱水。

序号对应 `/todo_links` 里的待脱水链接序号。

例如：

```text
/done 1
```

成功后，机器人会把对应卡片里的状态从：

```markdown
- 状态：待脱水
```

改成：

```markdown
- 状态：已脱水
```

异常输入时，机器人会给出提示：

```text
/done      → 请指定要标记的序号，例如：/done 1
/done abc  → 序号无效，请输入数字，例如：/done 1
/done 0    → 序号不能小于 1，请输入 /done 1 或更大的数字。
/done 999  → 如果序号超出范围，机器人会提示当前可用序号。
```

然后 `/stats` 里的“已处理”和“完成率”会自动变化。

### `/done_links`

查看已脱水链接的简洁列表，只显示链接，不显示完整 Markdown 卡片。

默认显示第 1 页，每页最多 10 条。

也可以指定页码，例如：

```text
/done_links 2
```

适合确认哪些链接已经处理完，也方便配合 `/undo` 恢复误操作。

异常页码时，机器人会给出提示：

```text
/done_links abc  → 页码无效，已显示第 1 页。
/done_links 0    → 页码不能小于 1，已显示第 1 页。
/done_links 999  → 如果页码超出范围，机器人会提示当前可用页码。
```

### `/undo`

把指定已脱水链接恢复为待脱水。

序号对应 `/done_links` 里的已脱水链接序号。

例如：

```text
/undo 1
```

成功后，机器人会把对应卡片里的状态从：

```markdown
- 状态：已脱水
```

改回：

```markdown
- 状态：待脱水
```

异常输入时，机器人会给出提示：

```text
/undo      → 请指定要标记的序号，例如：/undo 1
/undo abc  → 序号无效，请输入数字，例如：/undo 1
/undo 0    → 序号不能小于 1，请输入 /undo 1 或更大的数字。
/undo 999  → 如果序号超出范围，机器人会提示当前可用序号。
```

然后 `/stats` 里的“已处理”和“完成率”会自动变化。

---

### `/all_links`

查看全部链接的简洁列表，只显示链接，不显示完整 Markdown 卡片。

默认显示第 1 页，每页最多 10 条。

也可以指定页码，例如：

```text
/all_links 2
```

适合快速总览整个素材库。

异常页码时，机器人会给出提示：

```text
/all_links abc  → 页码无效，已显示第 1 页。
/all_links 0    → 页码不能小于 1，已显示第 1 页。
/all_links 999  → 如果页码超出范围，机器人会提示当前可用页码。
```

### `/platforms`

查看当前素材箱里各个平台的链接数量。

例如：

```text
/platforms
```

回复示例：

```text
当前素材箱平台统计：

- bbc.com：1 条
- linux.do：2 条
- x.com：5 条
```

### `/platform`

查看指定平台的链接简洁列表。

平台名对应卡片里的 `- 平台：...` 字段。

例如：

```text
/platform linux.do
```

也可以指定页码，例如：

```text
/platform x.com 2
```

回复示例：
```text
平台 linux.do 共有 2 条链接，正在显示第 1/1 页：

提示：这里显示的是全局序号，可直接用于 /card、/note、/tag、/fetch_title。

全局#6. https://linux.do/t/topic/2169822
全局#8. https://linux.do/t/topic/2175361
```

异常页码时，机器人会给出提示：

```text
/platform x.com abc  → 页码无效，已显示第 1 页。
/platform x.com 0    → 页码不能小于 1，已显示第 1 页。
/platform x.com 999  → 如果页码超出范围，机器人会提示当前可用页码。
```

如果输入的平台不存在，机器人会提示先用 `/platforms` 查看已有平台。


注意：`/platform` 返回的是全局序号，不是平台内部序号。这个序号可以直接用于 `/card`、`/note`、`/tag` 和 `/fetch_title`。

### `/search`

搜索素材箱里的卡片。

搜索范围包括标题、平台、链接、标签、状态和备注等卡片内容。

例如：

```text
/search AI工具
/search linux
/search BBC
```

回复示例：

```text
找到 1 条包含“AI工具”的卡片，最多显示前 10 条：

全局#1｜x.com
标题：示例文章标题一 / X
链接：https://x.com/example/status/1234567890
```

如果没有找到匹配内容，机器人会提示没有找到对应卡片。

异常输入时，机器人会给出提示：

```text
/search  → 请填写搜索关键词，例如：/search AI工具
```

### `/card`

查看指定链接的完整 Markdown 卡片。

序号对应 `/all_links` 里的全部链接序号。

例如：

```text
/card 1
```

成功后，机器人会返回该条链接的完整卡片，包括标题、来源、平台、链接、标签、状态和备注。

异常输入时，机器人会给出提示：

```text
/card      → 请指定要标记的序号，例如：/card 1
/card abc  → 序号无效，请输入数字，例如：/card 1
/card 0    → 序号不能小于 1，请输入 /card 1 或更大的数字。
/card 999  → 如果序号超出范围，机器人会提示当前可用序号。
```

### `/tag`

给指定链接添加或更新标签。

序号对应 `/all_links` 里的全部链接序号。

例如：

```text
/tag 1 #AI工具
```

如果输入标签时没有写 `#`，机器人会自动补上。

例如：

```text
/tag 1 AI工具
```

会自动保存为：

```markdown
- 标签：#AI工具
```

成功后，机器人会把对应卡片里的标签从：

```markdown
- 标签：#待分类
```

改成：

```markdown
- 标签：#AI工具
```

异常输入时，机器人会给出提示：

```text
/tag              → 请指定链接序号和标签，例如：/tag 1 #AI工具
/tag abc #AI工具  → 序号无效，请输入数字，例如：/tag 1 #AI工具
/tag 0 #AI工具    → 序号不能小于 1，请输入 /tag 1 或更大的数字。
/tag 999 #AI工具  → 如果序号超出范围，机器人会提示当前可用序号。
/tag 1            → 请填写标签，例如：/tag 1 #AI工具
```

### `/fetch_title`

尝试抓取指定链接的网页标题，并写回卡片。

普通抓取失败时，会尝试用 Jina Reader 兜底。

发送新链接时，机器人也会自动尝试抓取标题；如果自动抓取失败，不影响保存，可以稍后用 `/fetch_title` 手动重试。

序号对应 `/all_links` 里的全部链接序号。

例如：

```text
/fetch_title 7
```

成功后，机器人会把对应卡片里的标题从：

```markdown
- 标题：待抓取
```

改成抓到的真实网页标题，例如：

```markdown
- 标题：特朗普：美国总统再访华，直面更强势崛起的中国 - BBC News 中文
```

注意：

```text
普通网页通常可以直接抓取标题。
X/Twitter、LinuxDo 等网站可能因为前端加载、登录墙、403 Forbidden 或反爬限制，导致普通抓取失败。
Jina Reader 兜底可以提高这类页面的抓取成功率，但仍不保证所有网站都能成功。
如果普通抓取和 Jina Reader 都失败，机器人会保留卡片，并提示稍后用 /fetch_title 重试。
```

### `/note`

给指定链接添加或更新备注。

序号对应 `/all_links` 里的全部链接序号。

例如：

```text
/note 1 这条先留着，后面适合脱水成 AI 工具卡。
```

成功后，机器人会把对应卡片里的备注从：

```markdown
- 备注：待补充
```

改成：

```markdown
- 备注：这条先留着，后面适合脱水成 AI 工具卡。
```

如果旧卡片没有备注字段，机器人会自动补上。

异常输入时，机器人会给出提示：

```text
/note              → 请指定链接序号和备注内容，例如：/note 1 这条值得后续脱水。
/note abc 这条不错 → 序号无效，请输入数字，例如：/note 1 这条值得后续脱水。
/note 0 这条不错   → 序号不能小于 1，请输入 /note 1 或更大的数字。
/note 999 这条不错 → 如果序号超出范围，机器人会提示当前可用序号。
/note 1            → 请填写备注内容，例如：/note 1 这条值得后续脱水。
```

### 未知命令提示

## 六、启动方式

先复制 `.env.example` 为 `.env`，并填入自己的 `BOT_TOKEN`：

```bash
cp .env.example .env
```

然后在 Warp 里执行：

```bash
cd ~/tg-bot-test
source .venv/bin/activate
python tg_bot_ignition.py
```

看到下面这句，说明启动成功：

```text
[系统状态] TG 机器人已启动，正在监听链接并保存为 Markdown...
```

停止机器人：

```text
Ctrl + C
```

如果 `Ctrl + C` 一时卡住，可以直接重新开一个终端窗口，再重新启动。
